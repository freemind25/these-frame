Chapitre 01
Presentation generale
1.1 Apercu de l'application
ThesisFrame est un environnement de redaction integre concu specifiquement pour les doctorants. L'application combine un editeur de texte riche, un assistant IA avec 39 prompts specialises, 11 outils de recherche et de correction, et des fonctionnalites d'export professionnel. L'objectif est de centraliser l'ensemble du processus de redaction de these en un seul endroit, depuis le brainstorm initial jusqu'a la publication d'articles.
L'application fonctionne en mode hors-ligne : si le serveur est inaccessible, elle initialise instantanement avec des donnees locales et affiche une banniere ambre. Toutes les fonctionnalites restent accessibles en mode degradé.
Fonctionnalites cles

Editeur riche (TipTap) ou mode texte brut, 39 prompts IA specialises (P1-P39), 10 modes d'ecriture IA, Directeur de these virtuel, Recherche dans 10 bases de donnees scientifiques, Correction grammaticale (LanguageTool + Harper), Export PDF et LaTeX, Diagrammes Excalidraw, Sauvegarde Google Drive.

1.2 Configuration requise
ThesisFrame est une application web accessible depuis n'importe quel navigateur moderne (Chrome, Firefox, Safari, Edge). Aucune installation logicielle n'est requise. Pour les fonctionnalites IA, une cle API est necessaire (voir section 4.4).
1.3 Premier demarrage
Au premier lancement, l'application charge automatiquement une structure de these par defaut (6 chapitres IMRaD : Introduction, Revue de litterature, Methodologie, Resultats, Discussion, Conclusion). Vous pouvez commencer a rediger immediatement dans le premier chapitre, ou modifier la structure via les modeles (section 7).
Chapitre 02
Interface et navigation
2.1 Barre laterale d'outils
La barre laterale gauche contient tous les outils de l'application. Elle est repliable : cliquez sur le bouton en bas pour basculer entre la vue etendue (224 px) et la vue compacte (56 px, affichant uniquement les icones et un indicateur de progression circulaire). En mode mobile, la barre laterale se transforme en overlay glissant.
La section superieure contient les 11 boutons d'outils. La section du milieu contient les controles de structure : basculer entre mode chapitres et mode parties, et le selecteur de modeles. La section inferieure affiche le nombre total de mots et le statut de connexion.
2.2 Onglets de chapitres
Les chapitres sont affiches sous forme d'onglets horizontaux defilants au-dessus de la zone d'edition. Chaque onglet affiche le numero du chapitre, son titre abrege, le nombre de mots, et un indicateur de statut colore. Cliquez sur un onglet pour naviguer vers ce chapitre. Le bouton "+" a droite permet d'ajouter un nouveau chapitre ou une nouvelle partie.
2.3 Zone d'edition
L'editeur prend la majeure partie de l'ecran. Deux modes sont disponibles : le mode riche (TipTap) avec mise en forme (gras Ctrl+B, italique Ctrl+I, souligne Ctrl+U) et le mode texte brut (textarea). Basculez entre les deux via le bouton dans la barre laterale. La sauvegarde automatique s'effectue 2 secondes apres chaque frappe.
2.4 Panneau d'aide (Guide / IA / Directeur)
Le panneau de droite (340 px) contient trois onglets accessibles via le bouton d'aide dans l'en-tete du chapitre :
Onglet Guide
Conseils de redaction structurees en 10 categories (60 items) : phases d'ecriture, structure, argumentation, style, revision, productivite, pieges courants, revue de litterature, mouvements rhetoriques, mise en page.
Onglet IA
Chat conversationnel avec l'assistant IA. Selectionnez un mode parmi 10 disponibles, posez votre question ou collez du texte, et recevez une reponse contextualisee avec la base de connaissances de 39 prompts.
Onglet Directeur
Soumettez votre chapitre au directeur de these virtuel pour obtenir une evaluation structuree : 2 points solides, des points a consolider, et une question exigeante. Les retours precedent et actuel sont affiches cote a cote.
Chapitre 03
Gestion des chapitres
3.1 Creation et suppression
Pour creer un nouveau chapitre, cliquez sur le bouton "+" a droite des onglets, puis selectionnez "Chapitre". Le chapitre est ajoute a la fin de la liste avec un titre par defaut. Pour le supprimer, faites un clic droit (ou appui long sur mobile) sur l'onglet du chapitre, puis choisissez "Supprimer". La suppression necessite une double confirmation (deux clics successifs dans un delai de 3 secondes) pour eviter les suppressions accidentelles.
3.2 Renommage et reordonnancement
Depuis le menu contextuel d'un onglet (clic droit), vous pouvez renommer le chapitre (appuyez sur Entree pour confirmer, Echap pour annuler), le monter ou le descendre dans l'ordre, ou ajouter un nouveau chapitre juste apres celui selectionne. L'ordre des chapitres est sauvegarde automatiquement.
3.3 Mode Parties
Activez le mode parties via le toggle dans la barre laterale. Les chapitres sont alors groupes sous des parties nommees (Partie I, Partie II, etc.). Vous pouvez creer des parties, les renommer, y deplacer des chapitres, et les supprimer. Les chapitres non assignes apparaissent dans une section separee. Ce mode est utile pour les theses thematiques comportant plusieurs grandes parties thematiques.
3.4 Suivi de statut et compteur de mots
Chaque chapitre possede un statut automatique : Brouillon (gris, 0 mots), En cours (ambre, des que vous commencez a ecrire), Soumis (bleu, apres evaluation par le Directeur), Revise (vert). Le compteur de mots est affiche dans l'onglet, dans l'en-tete du chapitre, dans la barre laterale (progression vers 80 000 mots), et dans le pied de page.

4.2 Base de connaissances : 39 prompts specialises (P1-P39)
L'assistant dispose d'une boite a outils de 39 prompts specialises, organises en 7 categories. Ils sont injectes automatiquement dans le prompt systeme et utilises de maniere proactive quand le contexte le justifie.

Conceptualisation et questions (P7, P8)
Reformulation de questions de recherche avec grille SAOSF, 3 variantes et hypotheses (P7), generation de cadre conceptuel avec operationnalisation (P8).
Methodologie (P6, P13, P19-P25, P39)
Evaluation critique de methodologie (P6), analyse statistique avec visualisations (P13), structuration de la section methodologie (P19), justification du choix (P20), echantillonnage (P21), instruments de recherche (P22), procedures de collecte (P23), considerations ethiques (P24), taille d'echantillon (P25), verification d'exhaustivite (P39).

Productivite et ecriture (P10, P11, P30, P31)

4.3 Le Directeur de these virtuel
Accessible depuis l'onglet "Dir." du panneau d'aide, le Directeur de these virtuel agit comme un professeur exigeant mais bienveillant. Il ne redige jamais pour l'etudiant, mais fournit une evaluation structuree comprenant : deux points solides maximum, des points a consolider, et une question exigeante obligatoire. Les retours precedent et actuel sont affiches cote a cote pour suivre la progression. Le statut du chapitre passe automatiquement a "Soumis" apres evaluation.

Chapitre 05
Les 11 outils integres
5.1 References bibliographiques
Cet outil offre une gestion complete des references. Saisissez manuellement vos references (titre, auteurs, annee, journal, DOI, type : article, livre, conference, these, chapitre, site web). Importez depuis Mendeley via OAuth, ou importez un fichier BibTeX. Verifiez vos references par lot contre les bases DOI : l'outil affiche le statut de chaque reference (valide / non trouve / incoherent / sans DOI) et peut corriger automatiquement les metadonnees. Exportez toutes les references au format BibTeX. Un accès direct a 7 bases de donnees academiques (Z-Library, Anna's Archive, HAL Science, etc.) est integre.
5.2 Guide de redaction
Le guide de redaction contient 60 items pratiques organises en 10 onglets : les 5 phases d'ecriture (exploration, planification, brouillon, revision, finalisation), la structure de la these, l'argumentation, le style academique, la revision, la productivite, les pieges courants (11 pieges identifies), la revue de litterature, les mouvements rhetoriques (Swales), et la mise en page. Chaque item contient des conseils actionnables et des points de verification.
5.3 Recherche de litterature scientifique
Quatre sous-onglets de recherche : Recherche multi-sources (10 bases : Semantic Scholar, OpenAlex, Crossref, HAL, arXiv, PubMed, DOAJ, CORE, Europe PMC, ERIC) avec resultats affichant titre, auteurs, annee, resume, DOI, nombre de citations. Consensus (synthese IA sur 220 M+ d'articles). Recommandations (articles similaires a partir d'un DOI). Resolution DOI (metadonnees d'un article a partir de son DOI). Pour chaque resultat, copiez le BibTeX, ajoutez aux references, ou consultez les articles lies.
5.4 Correcteurs (LanguageTool + Harper)
Deux correcteurs sont disponibles et analysent le contenu du chapitre actif. LanguageTool detecte les erreurs (fautes de frappe, grammaire) et les avertissements (style, redondance, familiarites). Harper effectue une analyse de style academique avec niveaux de severite (erreur, avertissement, info). Pour chaque probleme detecte, un bouton "Appliquer" permet de corriger directement dans l'editeur en un clic.
5.5 Equilibre des chapitres
Cet outil affiche un graphique a barres du nombre de mots par chapitre, avec un code couleur : vert (equilibre correct), ambre (limite), rouge (desequilibre critique). L'outil distingue l'intro et la conclusion (traitees en pourcentage) et fournit des recommandations specifiques pour reequilibrer la these. Le verdict global est affiche en bas : bon / attention / critique.
5.6 Trouver un journal en acces ouvert
Recherchez des journaux scientifiques en acces ouvert via OpenAlex et DOAJ. Filtrez par domaine (15 champs proposes), APC (frais de publication), indexation Scopus, et triez par pertinence, APC croissant ou citations decroissantes. Les resultats incluent : nom du journal, ISSN, editeur, pays, APC, licence, processus de relecture, sujets, nombre d'articles, et liens directs vers la page d'accueil et la page de soumission.
5.7 Diagrammes (Excalidraw)
Un editeur Excalidraw complet est integre pour creer des diagrammes, schemas conceptuels et illustrations. L'editeur se charge dynamiquement et supporte le dessin libre, les formes, les fleches, le texte. Exportez vos diagrammes en PNG ou SVG. La sauvegarde automatique se fait dans le localStorage du navigateur.
5.8 Sauvegarde Google Drive
Connectez votre compte Google Drive via OAuth2 pour sauvegarder votre these dans le cloud. Uploadez le fichier, consultez la liste des fichiers sauvegardes, et ouvrez-les directement dans Google Drive. L'etat de connexion (email, derniere synchronisation) est affiche en permanence.
5.9 Recherche plein texte
Effectuez une recherche plein texte a travers tous les chapitres de votre these. L'indexation utilise TF-IDF avec un lemmatiseur francais. La recherche est debouncee a 300 ms. Les resultats affichent le numero du chapitre, le titre, un extrait avec les termes surlignes, et le score de pertinence. Cliquez sur un resultat pour naviguer directement vers le chapitre correspondant. Un bouton "Reindexer" force la mise a jour de l'index.
Chapitre 06
Export et sauvegarde
6.1 Sauvegarde automatique
La sauvegarde automatique se declenche 2 secondes apres chaque frappe. L'interface affiche un indicateur de statut : "Sauvegarde..." (spinner ambre) puis "Sauvegarde" (coche verte pendant 2 secondes). En cas d'erreur, un indicateur rouge s'affiche. Le compteur de mots est mis a jour automatiquement a chaque sauvegarde.
6.2 Export PDF
L'export PDF est genere cote serveur pour un rendu professionnel. Configurez les metadonnees du document (titre, auteur, directeur, universite, faculte, departement, mots-cles), choisissez un filigrane (aucun, BROUILLON, CONFIDENTIEL, VERSION PROVISOIRE), activez la table des matieres et la numerotation des pages. Selectionnez les chapitres a inclure. Le PDF est telecharge directement dans votre navigateur.
6.3 Export LaTeX
Exportez votre these au format LaTeX (.tex) via le modele integre. Le fichier genere est un document complet pret a etre compile avec Tectonic ou pdflatex. Cet export est utile pour les doctorants qui souhaitent travailler avec un editeur LaTeX externe ou soumettre a une institution exigeant ce format.
Chapitre 07

Commencez par le modele IMRaD classique. Il correspond a la structure la plus courante et est utilise comme reference par la plupart des comites de these. Vous pourrez toujours reorganiser les chapitres par la suite.

Astuce : blocage d'ecriture ?

Utilisez le mode IA "Paraphrase" avec le prompt P30 (Strategies contre le blocage). L'assistant diagnostiquera la cause du blocage (cognitif, emotionnel, procedurel, physiologique) et proposera un plan de reprise en 3 jours avec objectifs progressifs.

Astuce : verifier votre methodologie

Apres avoir redige votre section methodologique, utilisez le prompt P39 (Verification d'exhaustivite methodologique). L'assistant parcourra une checklist de 9 categories et identifiera les elements manquants avec les formulations a ajouter.

Astuce : preparer la soutenance

Le mode IA "Simulation de soutenance" (P12) genere des questions par chapitre (comprehension, critique, ouverture). Fournissez les profils des membres du jury pour des questions personnalisees. La strategie de reponse "je ne sais pas" est incluse.
